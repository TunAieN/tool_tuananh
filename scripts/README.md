# Scripts

- `build.ps1`: restore, build và test solution.
- `run.ps1`: build rồi chạy Manager.
- `release.ps1`: publish và tùy chọn build installer cục bộ.
- `SYNC_VERSION.ps1`: đồng bộ manifest từ `VERSION.txt`.
- `BUILD_V13.bat`, `BUILD_RUN_V13.bat`: wrapper tương thích cho quy trình cũ.
- Các script `TAO_*`: legacy release wrappers, đã cập nhật theo cấu trúc mới.

Không commit output do các script tạo ra.
